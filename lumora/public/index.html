        Lights

        Names show on the Devices tab and in automations. Removing a light also takes it out of automations, and an automation with nothing left to do is deleted. A scan can find it again.

        Offline detection

        Lumora knows a light is offline only if Home Assistant says so. Some bulbs keep showing “on” in Home Assistant even when they are unplugged. For those, add Home Assistant’s Ping integration with the bulb’s address (give the bulb a fixed address in your router first), then choose its sensor below.

        Phone alerts

        Lumora asks Home Assistant to send these to your phone, so they arrive even when this page is closed. You need the Home Assistant app on your phone, signed in.

          Use Lumora on a TV

          Easiest way for Google TV or Android TV, three steps:

          1. On the TV, install the free Downloader app from the Play Store and open it.
          2. In Downloader’s address box type this short address, choose Go, then Install:

          1. Open Lumora on the TV, choose Find my server automatically, then Sign in with a code from my phone. If it can’t find the server, type this address:

          1. Google TV or Android TV: follow the three steps above. The same page is at /tv on your server if you would rather read the steps on the TV.
          2. Samsung TV: build the Lumora app from the tv-samsung folder in Tizen Studio and install it on the TV in developer mode. The add-on’s documentation has the steps.
          3. On the TV choose Sign in with a code from my phone, then enter the code under Approve a TV below.

          No app yet? The address also works in a TV browser, and Chrome’s Cast shows Lumora on the TV, but the TV remote can’t control a cast screen. In the apps the remote’s arrows, OK and Back all work.

          Approve a TV

          Enter the code shown on the TV. Only approve a code you can see on your own TV right now.

          TV and remote

          Colored remote buttons
          Show remote help bar

          With a TV remote: arrows move, OK selects and Back goes back. On a brightness bar, OK starts adjusting and the left and right arrows change it. Red turns all lights off. Green, Yellow and Blue run the Evening, Movie and Bright scenes.
